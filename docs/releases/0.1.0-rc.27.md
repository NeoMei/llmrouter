# LLMRouter v0.1.0-rc.27

本次为服务端预发布，包含登录入口统一、托管原生 CREDIT 计量（默认关闭）与配置快照修复三项内容。

身份与用户目录：产品登录入口收敛到 UniHub，LLMRouter 只有在既未接入 UniHub、也未开启浏览器单点登录的纯原生部署下才显示本地运维登录。用户页对中心管理员读取 UniHub 的中心用户目录，只呈现标识、名称、邮箱、角色、状态与授权版本，不暴露本机档案、凭据、余额、额度或路由价格分组。

原生 CREDIT 计量：托管原生 Key 新增按 CREDIT 结算的路径，仅在平台下发 `llmrouter_native_credit` 计价且换算参数合法时启用；缺失或非法时拒绝该路径结算，不退回人民币计价。该能力默认关闭，本次未改变线上任何费率、开关或既有账单。

网关适配器配置快照：适配器创建后，外部修改原配置中的请求体大小限制或操作费率映射，不再改变该适配器已采用的限制与费率标识。覆盖嵌套映射修改与删除的回归测试已通过，并通过定向竞态检查。

同时移除误入版本控制的 Python 缓存并忽略后续缓存；不涉及数据库结构或依赖升级。部署保留账户、钱包、API 密钥、历史账单、模型目录、价格与路由配置。

本次提供 Linux amd64 二进制、源码归档、部署压缩包与完整性元数据。

This server prerelease unifies the sign-in entry, adds opt-in managed native CREDIT metering and fixes configuration snapshots.

Sign-in and user directory: the product sign-in path is consolidated onto UniHub. LLMRouter keeps a local operator sign-in only for purely native deployments that have neither UniHub access nor browser single sign-on. The user page reads the UniHub central directory for central administrators and shows identifiers, display name, email, role, status and assignment version only — never native profiles, credentials, balances, quotas or route or pricing groups.

Managed native CREDIT metering: managed native keys gain a CREDIT settlement path that engages only when the platform issues `llmrouter_native_credit` pricing with valid conversion parameters. Missing or invalid parameters refuse that path instead of falling back to CNY pricing. The capability ships disabled and no live rate, switch or existing bill is changed by this release.

Adapter configuration snapshots: once an adapter is constructed, later changes or deletions in the caller's nested request-body-limit or rate-ID maps no longer alter the limits and rate identifiers it already adopted. Regression tests and a focused race check cover the snapshot behavior.

The release also removes an accidentally tracked Python cache and ignores future cache files. Database schemas and dependencies are unchanged. Deployment preserves accounts, wallets, API keys, historical bills, the model catalog, prices and routing configuration.

This prerelease provides a Linux amd64 binary, source archive, deployment archive and integrity metadata.
