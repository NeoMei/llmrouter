# LLMRouter v0.1.0-rc.32

本次解决同一类问题的最后一环：供应商已经执行完成、但我方拿不到结果的 OCR 任务，原来没有任何终态出口——既不能成功结算（没有可交付结果），也不能失败释放（`Finish` 只接受 `provider_state=failed`），于是一直停在 `reserved`，worker 每 10 秒重试并失败，UniHub 侧的预留也就一直挂着。生产上正是 4 条：`provider_state=done`、`billing_state=reserved`、`result_resource_id` 为空，PaddleOCR 结果地址持续返回 403。

修复：

- `model`：`Finish(failure)` 增加一种合法情形——`provider_state=done` 且没有可交付结果时允许结为失败。原来只接受 `failed`，导致这类任务无出口。
- `service/ocr`：结果下载持续失败且**已超过保留期**时，按失败结单并走释放路径；未超过保留期仍然重试，因为供应商可能只是结果尚未写完（生产测试里就有第 2 次轮询临时 403、之后恢复的情形）。
- 官方 PaddleOCR 会把结果分片到 `paddleocr-store-2` / `paddleocr-store-6` 等主机，而代码只认 `paddleocr-store`，导致这些任务在下载前就被来源校验拒绝、永远无法归档。现在官方结果主机按受信family匹配（仅 `paddleocr-store(-N)?.bj.bcebos.com`、仅 https、无端口、无用户信息），其它域名、相似后缀、http 或带端口仍然拒绝。
- 真正的来源校验失败、身份不符仍按错误返回，不参与结单、不动资金：那可能是攻击，不能被当成业务失败顺手退款。
- 平台释放路径现在接受「供应商已执行但结果不可交付」，把该任务的 UniHub 预留退回。

取舍：结果超过保留期仍不可取，判定为失败退款。若上游其实存在结果只是长期不可达，用户得到一次未扣费的失败，方向上宁可不收、绝不扣了钱不交付。

This release closes the last exit hole for OCR jobs the supplier finished but whose output cannot be retrieved. Such a job could neither settle (no deliverable result) nor release (Finish accepted only provider_state=failed), so it stayed reserved while the worker retried and failed every ten seconds, holding the UniHub reservation indefinitely. Four production jobs were in exactly that state.

The official Paddle OCR service shards results onto hosts such as paddleocr-store-2 / paddleocr-store-6 while the code accepted only paddleocr-store, so those jobs were rejected before any download and could never be preserved; official result hosts are now matched as a trusted family (exact sharded host pattern, https only, no port, no user info) while look-alikes stay rejected.

Changes: Finish(failure) accepts a done provider with no deliverable output; the service ends such a job as a failure once it is past its retention window and still unavailable, while retrying inside that window because a 403 can be transient; origin and identity rejections remain errors that never move money; the platform release path now accepts a finished-but-undeliverable job and returns the reservation.
