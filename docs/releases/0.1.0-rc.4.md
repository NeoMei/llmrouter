# LLMRouter v0.1.0-rc.4

修复 UniHub 已登录但无法进入 LLMRouter 控制台的问题。原先只有独立账户工作台的身份验证，主界面仍要求本地会话；现在服务端验证 UniHub 产品身份后按发行方和不可变用户 ID 建立普通业务投影并签发产品会话，前端进入控制台并保留安全的站内目标。

统一资源、团队、充值订单和用量继续由 UniHub 授权；既有本地用户与运营账号保持原路径。投影不能使用本地资金、推荐奖励、密钥或管理员操作，也不按同名/邮箱迁移旧账号。账户切换保留未确认财务操作的原始幂等键。

UniHub 产品令牌仅存内存；刷新可以恢复产品外壳，但查询 UniHub 资源须重新授权。退出撤销产品会话并清空统一账户状态。

本次仍为沙盒预览，真实支付未接入，公开真实模型入口保持关闭。不是签名 GA、真实支付或模型开放声明。验证记录区分自动化夹具、服务器迁移和公网浏览器实测。
