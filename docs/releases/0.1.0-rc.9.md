# LLMRouter v0.1.0-rc.9

修复 UniHub 身份登录后原有应用界面被账户面板替换的问题。统一身份继续进入 LLMRouter 的产品控制台，UniHub 账户作为独立菜单入口。

- 恢复原有应用布局、侧栏和页面路由，支持概览、模型/流量分析、本人调用日志及直接访问/刷新。
- 修复产品页面的前后端白名单不一致，并为真实业务数据接口补齐当前身份与权限检查。
- 明确分开个人数据与全局管理数据，产品管理权限按 catalog、log、routing、settings 和既有 channel 能力显式授予；中央权限撤销继续影响原有会话。
- 产品运行设置仅开放明确字段；UniHub 保留身份、账户、团队、钱包及计费。普通用户不会自动成为管理员，也不会获得本地额度、原生 PAT 或供应商秘密。

本版为服务端 RC。实际部署、浏览器验收及校验和以同批发布资产的脱敏验收记录为准。未进行真实模型供应商请求或支付，不声明桌面安装、签名、公证、多实例或 GA 验收。
