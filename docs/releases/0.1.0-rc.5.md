# LLMRouter v0.1.0-rc.5

候选准备日期：2026-10-26。这是 native metering 的沙盒预览候选版：将对话、embedding、语音、转写、图片、OCR 和视频的计量单位明确绑定到供应商实际用量或成功输出，并把本地账本与 UniHub 平台结算保持在同一份精确数量契约上。

## 更新内容

- 对话和 embedding 按供应商实际 token 计量；缺失、重复或冲突的 usage 保持待核对，不用估算值冒充实际值。
- TTS 按字符计量，STT 按音频秒数计量；供应商回执和受限 PCM WAV 的服务端测量各有明确准入策略。
- 图片按成功输出数和受信任的尺寸档位计量；无法验证远端尺寸时保持待核对，不把请求参数当成实际输出。
- OCR 按成功请求计量，页数计量暂未启用。
- 视频按供应商实际单位或成功输出秒数计量；不支持的 Veo、多输出和未认证回执在预扣费前拒绝。
- 预留、结算、恢复、未知结果和管理员释放均保持幂等；SQLite、MySQL 5.7 和 PostgreSQL 9.6 的账本路径使用相同的安全边界。既有 legacy 价格只有在显式启用 `metered_v2` 时才会切换。

## 验证与边界

本候选已完成后端、并发、三种数据库、路由供应商协议夹具、异步生命周期、UniHub 精确结算、SDK、前端和本地浏览器验收；完整记录见[计量覆盖](../native-metering-coverage.md)和[验证记录](../native-metering-verification.md)。这些证据是自动化和隔离环境验收，不等于真实供应商认证或生产发布门禁。

本版本不发布真实价格或生产供应商凭据，不宣称签名 GA、已认证容器、桌面签名制品或公开真实模型入口。供应商可能已接受但本地未取得最终回执的请求会保持 UNKNOWN 并等待对账；STT 当前只接纳受限 PCM WAV 的服务端测量，其他编码需要独立认证的测量适配器。

升级前请备份数据库、对象存储、现有镜像与配置；生产部署仍需通过现有签名、供应商认证、容器证明和恢复演练门禁。
