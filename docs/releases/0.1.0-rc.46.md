# LLMRouter v0.1.0-rc.46

本版在钱包页新增真实现金充值入口：用户输入充值金额（最低 ¥1、最高 ¥100000，最多 2 位小数）或点选 ¥20/50/100/300/1000 快捷档位，选择微信支付或支付宝后跳转到 UniHub 收款页完成付款。付款成功后由 UniHub 回调验签并以 cash_topup 幂等记入产品钱包现金余额。

充值请求经 LLMRouter BFF 透传到 UniHub 的 POST /v1/accounts/{account}/cash-checkouts（携带 CSRF 与 Idempotency-Key）。中央身份与 runtime finance 两套 BFF 允许清单均已放行 cash-checkouts；七种语言补齐相关文案。

本版依赖 UniHub v0.4.57 提供cash-checkouts API 与 031 迁移。支付商户主体、回调域名与支付密钥沿用 UniHub 现有支付配置，本版不引入新凭据。
