# LLMRouter v0.1.0-rc.25

Managed Alibaba embeddings now use the vendor model ID `text-embedding-v4` throughout admission, route generation hooks, policy lookup and the knowledge binding operator. The retired service-prefixed model ID is no longer a managed knowledge identity.

The change retains the signed embedding-space contract, 1024-dimension floating-point validation, original account Key and payer, request deduplication and settlement checks. It does not rewrite historical calls, quotes or immutable route pins, and it does not rebuild existing user knowledge indexes.

Existing installations require a separately reviewed configuration migration to select the intended canonical route, preserve the exact embedding space, retire the old active bindings and create new canonical bindings. No automatic migration or compatibility alias is added by this prerelease.

Regression coverage exercises canonical public model calls through the original account Key, strict signed policies, duplicate and revocation rejection, route/channel mutation fencing, transactional operator rollback and rejection of the retired ID before billing or supplier dispatch. The prior Bailian WAV delivery repair remains included.
