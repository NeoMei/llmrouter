# LLMRouter v0.1.0-rc.23

Account API keys can use explicitly configured Qwen native speech routes. The gateway validates the selected target, reserves the configured supplier-character bound, and settles the supplier's reported usage before returning validated WAV audio. Chinese input admission accounts for the supplier's two-unit character rule. A target or supplier credential change during the final account authorization prevents dispatch.

Speech discovery requires an executable native route, a compatible audio policy, an explicit character tariff and a reservation limit. Existing per-request prices remain unchanged. Missing usage and uncertain supplier outcomes retain their existing recovery states without another synthesis.

Embedding catalog names now attribute the legacy compatibility route to Alibaba using its declared embedding-space identity. Public model IDs, knowledge generation pins and persistent model metadata remain unchanged.

An authenticated Alibaba compatible Chat response that explicitly rejects a missing model now records bounded rejection evidence and releases its reservation. Ambiguous responses, transport failures and inconsistent evidence remain unresolved. Historical platform-fault waivers also accept SuperWagie-origin calls while preserving the original payer and supplier state.

Regression coverage includes same-Key speech, exact supplier usage settlement, Chinese reservation bounds, changed targets, duplicate requests, unsupported audio policies and model attribution. Production configuration and real-call acceptance are recorded separately from these controlled tests.

This prerelease targets the Linux amd64 server. Deployment changes only the application version in the environment and requires no database schema migration.
