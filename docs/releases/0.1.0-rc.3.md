# LLMRouter v0.1.0-rc.3

发布日期：2026-10-25。此版本沿用源码候选版发布方式，附带供受控部署验收的 Linux amd64 候选二进制。它不是签名 GA、桌面安装包或已认证容器；服务器部署状态另行记录。

## 更新内容

- UniHub 可选集成支持独立账号模式及统一注册、登录、个人/团队选择、付款方与按角色授权的财务操作。产品界面调用 headless API，身份、钱包、会员、积分和账本仍由 UniHub 掌管。
- 平台模式模型请求经 UniHub 预留、结算和恢复，不消耗本地 quota；重复请求、结算响应丢失及重启恢复保持一次供应商派发与一次结算边界。未知派发状态继续进入对账。
- 金额保留 CREDIT/6、CNY/6 的资产类型及精确整数字符串，混合资产报表不生成跨资产合计。产品身份使用精确匹配，避免相似产品身份继承权限。
- 包含上游零价格 OCR 余额判断修复；保留 rc.2 的账号池、OCR 持久任务及多媒体协议能力。

## 验证与升级

本候选基于合并提交 `90fe88d2a`，包括上游 `0f6330f5e`。版本提交仅修改 VERSION 和本说明。候选准备记录保留完整 Go、平台 race、前端单元、浏览器协议夹具、类型检查、受影响文件 lint 与生产构建结果及制品 SHA256。

[本地集成验收记录](../integrations/unihub-validation-2026-10-25.md)记录实际 Casdoor、隔离 PostgreSQL/Formance 账本和受控模型供应商的验证；这些既有证据不等于本候选重新完成真实供应商认证、真实商户支付或生产验收。浏览器协议夹具也不等于真实身份/账本验收。

升级前备份数据库、对象存储、现有镜像与配置。按[集成指南](../integrations/unihub.md)配置平台身份、可信源和密钥；未启用平台模式时保留既有独立模式。真实采购账号容量、模型权限及真实支付另行验收。

正式签名制品和 GA 仍必须通过现有签名、真实供应商认证、容器证明及恢复演练门禁。本候选不绕过或宣称通过这些门禁，不包含私有夹具、运行环境或凭据。
