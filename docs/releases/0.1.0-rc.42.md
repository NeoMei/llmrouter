# LLMRouter v0.1.0-rc.42

本版把默认渠道连通性检查、30 分钟定时保活和批量渠道检查统一改为只读的模型目录探活。这些入口只发送无请求体的受限 `GET /models`（或相应渠道的只读模型列表端点），带 5 秒超时、64 KiB 响应上限、禁止跳转与错误脱敏，不生成图片、语音或视频，不改动渠道启停状态，也不写消耗记录。无法确认安全只读端点的渠道会返回明确的拒绝结果。

真实生成测试仅保留在 `POST /api/channel/test/:id/deep`：它受 `authz.ChannelSensitiveWrite`、`X-Channel-Deep-Test: confirmed` 请求头和请求体 `confirm: true` 三重限制，供管理员显式单独确认。前端根据 `probe_mode` 区分「连通性检查」和「生成测试」，七种语言的新增文案均已补齐。

Default channel tests, the 30-minute scheduled keepalive, and batch channel tests now use a bounded, read-only model-list request. They have no request body, do not follow redirects, do not enable or disable channels, and do not generate content. Real generation remains available only through the separately confirmed `POST /api/channel/test/:id/deep` endpoint.
