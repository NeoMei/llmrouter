# LLMRouter v0.1.0-rc.27

修复网关适配器的配置快照：适配器创建后，外部修改原配置中的请求体大小限制或操作费率映射，不再改变该适配器已采用的限制与费率标识。覆盖嵌套映射修改与删除的回归测试已通过，并通过定向竞态检查。

本次为服务端维护预发布，包含 Linux amd64 二进制、源码、部署压缩包与校验信息。移除误入版本控制的 Python 缓存并忽略后续缓存；不涉及数据库结构或依赖升级。部署保留账户、钱包、API 密钥、历史账单、模型目录、价格与路由配置。

Gateway adapters now retain an independent snapshot of operation body limits and rate ID mappings. Changes or deletions in the caller's nested configuration maps no longer alter an adapter that has already been constructed. Regression tests and a focused race check cover the snapshot behavior.

This server maintenance prerelease provides a Linux amd64 binary, source archive, deployment archive and integrity metadata. It removes an accidentally tracked Python cache and ignores future cache files. Database schemas and dependencies are unchanged. Deployment preserves accounts, wallets, API keys, historical bills, the model catalog, prices and routing configuration.
