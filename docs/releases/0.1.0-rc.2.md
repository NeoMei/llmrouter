# LLMRouter v0.1.0-rc.2

发布日期：2026-10-25。此版本为源码候选版。未附带通过签名及真实供应商认证的正式二进制、桌面安装包或容器制品；服务器部署状态单独记录。

## 更新内容

- 选择性同步 New API 和 OpenCodex 的传输超时、重试控制、Claude 用量与缓存计费、流式交付及协议兼容修复。
- 原生多 Key 与 Gateway 采购账号池：健康轮询、受预算约束的账号切换、操作/模型冷却、共享配额组、凭据隔离、手动暂停和恢复。异步资源沿用实际创建账号。
- 已接入选定的国产图片/音频/视频理解、ASR、TTS、同步图片生成与编辑、PaddleOCR、文本向量、Ali 重排和多模态向量协议。具体模型、媒体范围和参数限制以运维指南为准。
- 管理 API 与界面展示账号池状态，支持权限受控的恢复操作；有效链式别名与显式目录目标使用一致的健康标识，保留既有计费身份。
- 对照 SuperWagie 资料库的实际固定后端客户端，验证 OCR、文本向量、SQLite vec0/FTS5 检索、重排及持久引用位置链路。
- OCR 保留持久任务、资金操作日志与消费日志去重回执；结果清理后的所属状态查询保持410，避免重新提交或扣费。

## 验证

生产代码修复提交为 `0228da9ceb60c9affcf1c6c34b1217be683165ba`；本轮版本提交只更新VERSION与发布说明。此前完整本地后端格式、测试、vet、race、构建及onboarding检查通过，实际启用SQLite、MySQL5.7.44、PostgreSQL9.6专用夹具；原项目合入后完整普通测试也通过。受影响前端单元、类型、lint、格式、Chrome场景和生产构建通过。

最终独立全分支审查的四项问题已一次修复并范围复审批准，无新增Critical/Important/Minor。真实固定消费者链验证精确额度、一次结算与引用位置；不代表完整桌面摄入或三数据库全消费者链。

## 升级与限制

- 升级前备份数据库、对象存储与现有镜像/配置。账号池、OCR和媒体资源增加持久表，由应用执行迁移。
- OCR、媒体下载授权、对象存储和视觉预留上限需要按指南配置；不会自动创建采购账号、供应商权限或迁移真实资料库。
- 真实采购账号的容量、模型权限、OCR/音视频/图片质量尚未验收；全部账号不可用时仍可能失败。流式已输出内容不能跨账号续接，暂停不取消已准入请求。
- 正式签名制品和GA发布继续受现有签名、真实供应商认证、容器证明及恢复演练门禁约束。本源码候选版不宣称这些门禁已通过。
