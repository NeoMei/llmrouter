# 0.1.0-rc.21 — Linux amd64 server preview

- Let a SuperWagie managed API Key use the current LLMRouter native model catalog without a second per-model allowlist or tariff. Keep the original Key, actor, personal or team payer, product wallet, budget and revocation checks.
- Quote and settle using frozen native model and supplemental prices. Reserve before dispatch, preserve zero-priced models, and never replay a provider request whose result is uncertain.
- Support the existing Chat, Responses, Claude, Gemini, embedding, rerank, image and OCR protocols under the same Key. Expose operation availability from enabled routes and channels; a configured but unavailable model is not reported as executable.
- Support native PaddleOCR channels configured as an enabled one-member pool while preserving the selected account and key hash through polling. Preserve private OCR task and document ownership. Reject supplier-private resource references that cannot be bound to the calling Key.

The database migration adds four nullable columns to platform_model_calls:
pricing_source, credential_version, native_price_snapshot and native_quote_json.
The new deployment opt-in is UNIHUB_NATIVE_ROUTING_GROUP=default. Preserve all
other runtime settings, including the read-only finance gate and the unset full
finance gate. Existing selected-model Keys retain their original policy.

Source verification, isolated restore and migration rehearsal, exact image
provenance, deployment and paid-call acceptance are recorded separately. Model
availability still requires an enabled supplier channel and applicable native
pricing; this release does not create supplier credentials or substitute models.

This is a Linux amd64 server prerelease, not a desktop or GA certification.
