# LLMRouter v0.1.0-rc.40

本版完善 DeepSeek Responses 搜索/抓取与模型目录的兼容性，并补齐 Chat 失败终态已消耗 token 的保留。

- Responses、Anthropic 兼容响应和 HTTP 200 内的生成失败，统一按终态 `usage.server_tool_use` 的 `tool_search`、`tool_fetch`、`tool_image_search` 计费；`web_search_requests`、`web_fetch_requests` 仅用于展示。终态计数（包括零值）覆盖流式暂存计数，缺失终态用量时才保留暂存值。
- 支持 `deepseek-flash-low` 与 `deepseek-v4-*-low` 思考强度后缀，映射到上游 `thinking.type=enabled` 和 `effort=low`。
- 官方 DeepSeek Responses 在工具调用及工具结果续轮前补齐明文 reasoning 占位，避免历史被上游拒绝；请求原始 JSON 字段保持不变。
- 上游模型同步不再把 `deepseek-search`、`deepseek-fetch` 当作过期模型，并统一应用新增/删除两侧的忽略规则。
- 新库 seed 与旧库安全升级将 DeepSeek 上下文窗口和最大输出更新为 1048576 / 393216；只修复仍等于旧 seed 哨兵值的记录，保留运营方修改。
- 普通 Chat Completions 与 Responses→Chat 在 HTTP 200 内返回生成失败时，保留厂商已报告的输入、输出和缓存 token；客户端仍收到错误，调用方可在原失败路径结算一次，不会跳过或不必要地重试。
- 按 2026-11-14 官方 CNY 价格（每千次成功请求 5 元，按 7.3 固定汇率折算）修正 text/image search 和 Fetch 价格，并为 `deepseek_image_search` 增加托管工具默认价。独立 `deepseek-search`、`deepseek-fetch` 内部请求价按每请求 `0.005 / 7.3` 美元同步修正；不虚构图片搜索独立路由。

DeepSeek Chat 的 `deepseek_web_search`、`deepseek_read_url`、`server_tool_calls` 仍不支持。SuperWagie `uh_model_` 托管路径的内置工具也仍不支持；两条路径继续拒绝未完成协议与冻结/结算契约的调用。

This release also preserves provider-reported tokens from HTTP 200 Chat generation failures. It uses DeepSeek's terminal `server_tool_use` counters for billing, adds the `-low` thinking suffix, repairs official Responses reasoning replay, protects internal tool routes from model-sync removal, upgrades legacy DeepSeek provider metadata within safe sentinels, and corrects Search/Fetch pricing to the published CNY rate. Chat server tools and SuperWagie managed-key hosted tools remain unsupported.
