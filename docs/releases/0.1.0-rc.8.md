# LLMRouter v0.1.0-rc.8

服务端预发布候选，配合 UniHub `v0.4.9` 的统一产品用户基础。产品身份和当前角色由 UniHub 管理，LLMRouter 保留自身业务用户、资源与运行配置。

## 更新内容

- 复用经过提交及 SHA256 校验的 Go 用户模块源码快照，使用浏览器 OIDC authorization code/S256 PKCE、签名和精确 issuer/audience 校验完成产品登录。同一中央身份在事务中幂等建立普通业务投影，不按邮件关联既有原生账号，不授予原生管理员、钱包余额或 API key。
- 上游身份 bearer 留在后端，使用持久会话密钥派生的 AES-GCM 加密，并绑定产品、实例、身份、本地用户、会话及有效期。浏览器通过随机 HttpOnly 会话及有界 BFF 访问账户与财务能力；写入继续检查精确 Origin、会话 CSRF 和已有财务幂等规则。
- 统一产品角色用于渠道访问，普通 member 默认拒绝渠道管理；viewer 可读，operator 按显式授权执行操作。每次受保护请求在线检查当前中央状态，撤回、停用、失效或中央不可用时拒绝，不回退到原生角色。
- 产品渠道接口返回经过筛选的 DTO；不向产品会话展示渠道密钥、携带凭据的 URL、私有配置和供应商错误元数据。局部编辑保留未展示的秘密，敏感操作继续执行独立授权；原生运维入口保持自身权限。
- 前端使用服务端会话恢复、当前权限和 BFF；渠道侧栏按权限显示。支持 `/channels`、`/dashboard` 等明确的产品页面深链，产品会话不再触发原生 2FA/passkey 凭据接口。
- 有界 OIDC discovery 合并并发初始化，只缓存成功结果；失败后下一次用户登录可恢复，无需重启，已成功 Browser 的一次性登录事务保持有效。产品退出清除本地会话，中央 IdP SSO 会话独立保留。

## 接入与源码边界

按[产品用户模块接入](../integrations/unihub-userkit.md)配置独立客户端、精确回调 `/api/unihub/callback`、实例、`access:read`、明确的账户/财务 scopes 和受信产品声明。UniHub 客户端登记中的 `browser_sso` 需显式开启，不隐式开启密码 API 或自助注册。中央用户管理员由独立不可变 UUID 配置；产品角色不会修改已存储的原生 common 角色或零配额。

共享模块继续使用本仓库 `third_party/unihub-userkit` 的相对源码替换，通过 `python3 scripts/sync-unihub-userkit.py --check` 校验。UniHub `v0.4.9` 另提供 kit/starter 源码资产及生成器；这不表示 Go nested-module tag 或 npm 包已发布，也不新增来源仓库未声明的许可授权。

`VERSION` 是本候选的服务端版本来源，构建继续通过 `common.Version` 链接注入及前端版本环境变量显示；web、CLI 和 Electron 各自既有 package 版本不在本次服务端发布中改号。

## 验收范围

[UniHub 本地验收记录](https://github.com/NeoMei/UniHub/blob/main/docs/integrations/product-user-foundation-acceptance-2026-10-27.md)记录真实本地 Casdoor、隔离中央 PostgreSQL、LLMRouter SQLite 与独立生成的 Notes 产品：同一中央 UUID 的跨产品 SSO、JIT 初始化一次、viewer/operator 分权、原有会话撤权、全局停用、页面深链与恢复均通过。产品投影保持 common 角色和零额度，受控渠道始终禁用，未进行供应商或资金操作。

另有签名 OIDC HTTP 夹具、中央证明夹具、隔离数据库、前端和浏览器协议回归，覆盖凭据隔离、权限边界、财务未决状态与 discovery 恢复；这些自动测试不替代真实提供方、生产部署或真实用户读回。实现与验收记录中的完整测试结果属于对应代码阶段，发布元数据和发布包检查需以本次发布实际执行结果为准。

本候选仍为 **server preview / release candidate**。Starter 的单进程存储、内存登录事务、多实例共享会话、生产 HTTPS/cookie 和外部 standalone IdP 需要单独接入验收。本次不声明桌面安装、签名、公证、容器供应链或 GA 验收；不扩大既有模型供应商、非聊天模态、真实商户收款或账单对账边界。UniHub 充值与会员资金仍为 sandbox。
