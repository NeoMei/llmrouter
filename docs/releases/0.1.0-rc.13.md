# 0.1.0-rc.13

- The default sign-in form accepts UniHub usernames and passwords when product integration is enabled, including UniHub TOTP verification.
- Existing local accounts remain available through the explicit native sign-in entry. Failed central authentication never selects a same-name local account.
- Configuration failures, account changes and leaving the sign-in page cannot install a stale central session.

The UniHub client must allow JSON password login. Cross-origin TOTP requires the companion UniHub MFA CORS fix.
