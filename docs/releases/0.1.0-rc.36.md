# LLMRouter v0.1.0-rc.36

本版修复生产库已有 provider 模型记录时启动阶段的唯一键冲突。

rc.35 已包含 DeepSeek 原生 Responses 搜索/抓取、独立 `/v1/tools/search` 与 `/v1/tools/fetch`、按已完成工具调用计费，以及当前模型目录和平地价。

启动种子现在使用数据库冲突跳过，只在缺失时创建内置 provider 与模型；重复启动不会尝试重复插入，也不会覆盖运营方已有的 URL、显示名或 quirk 设置。生产 `provider_models` 的现有行保持不变。

This patch makes the provider catalog seed safe against existing rows. It skips a conflicting profile or model without overwriting operator edits, fixing a duplicate-key startup loop on the production database. The DeepSeek hosted-tool behavior from rc.35 is unchanged. DeepSeek Chat server tools and managed-key hosted tools remain unsupported until their separate contracts are implemented.
