# LLMRouter v0.1.0-rc.11

保留原系统完整功能的 UniHub 适配。

- 原用户 ID、认证器、注册登录、Key、分组限制、用户管理、额度调整、流量监控和业务页面继续使用原流程，身份来源不再切换到另一套产品功能。
- 原入口完成认证后可建立中央浏览器会话，无感进入其他已接入产品；首次用户执行原产品赠额、设置和默认 Key 策略，重入不重复初始化。
- 通过原计费接口对接实例隔离的中央最终账本，保留原计量与价格计算；套餐内消费不重复扣钱包，退款和异步费用调整固定原付款人、Key 与价格。
- Key 撤销、过期、删除或用户停用会拒绝新调用，已接受的费用仍可按原责任恢复结算。已知拒绝和未知结果分别处理，重复请求不重复扣费。
- 旧资金切换要求经过审核的停机、批量及缓存核账证据；身份映射不会自动搬迁余额，邮箱相同不会自动合并用户。

本地 Go race、原应用浏览器页面及真实 HTTP/TLS、PostgreSQL/SQLite/Formance 跨仓库验收通过。原调用结算 37 后余额 463，撤销 Key 后原费用调整至 47 只补扣一次 10，新调用继续拒绝，最终余额 453。此版本发布不等于真实支付、外部模型供应商或桌面安装包验收。
