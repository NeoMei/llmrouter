# LLMRouter v0.1.0-rc.38

本版只修复 DeepSeek Search/Fetch 端到端测试的清理竞态：空结果的异步退款尚未结束时，测试先恢复了全局数据库指针。现在测试会在恢复全局状态前排空后台退款 worker。

生产计费行为不变：Search/Fetch 仍只对非空成功结果收费，空结果释放预扣。DeepSeek Chat 服务端工具与 SuperWagie 托管 hosted tools 仍暂不支持。

This release only drains asynchronous refund workers before the DeepSeek Search/Fetch test restores global test state. Production billing behavior is unchanged. Chat server tools and managed-key hosted tools remain unsupported.
