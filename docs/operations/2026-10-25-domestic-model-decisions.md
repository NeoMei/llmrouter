# 国产模型账号池实施决策

按实施顺序记录全部54项自主决策及其代价，详细依据和原始记录随完整验收证据归档。编号保持历史顺序；这些选择不扩大已验证的供应商能力。

**Rulings I made**

1. 沿用隔离工作树自主实施；选错范围需返工，不动用户数据。
2. 共享代码分段实施并独立审查；代价是额外耗时。
3. 数据库作为健康权威，首批不加 Redis 加速；代价是更多数据库访问。
4. 验证后才本地快进，不碰真实采购凭据；真实供应商验收仍需后续执行。
5. 增加私有成员映射与协调表；代价是少量持久化元数据。
6. OCR 下载使用限时资源授权；授权地址需要保密并管理过期撤销。
7. 行锁依据实际事务数据库判断；代价是共享锁辅助逻辑改动。
8. 共享配额组跨池生效；配置错误可能同时冷却多个池。
9. OCR 使用持久化资金操作日志；不确定状态可能需要人工核对。
10. 公共标识大小写精确，内部使用规范哈希；代价是新增内部编码规则。
11. Gateway 区分账号与凭据代际，原生替换 Key 不冒认同账号；旧原生任务可能无法恢复。
12. 未纳管的讯飞/实时 WebSocket 禁止账号池；这些入口暂不能池化。
13. Midjourney 独立路径、Bedrock SDK 暂不池化；相关旧功能仅保留原单账号行为。
14. 目标可声明匹配的固定向量空间；代价是新增元数据，供应商权重仍无法由声明证明。
15. 公开别名交由统一目录解析；代价是分发逻辑及权限回归改动。
16. 撤掉适配器明确不支持的能力声明；能力目录范围会收窄。
17. 未整合原生任务拒绝显式公开路由；这些路径暂不能使用该路由能力。
18. 无法证明语义安全的参数覆盖在预扣前拒绝；部分自定义覆盖暂不可用。
19. 显式路由的原始 Responses 修正最终模型；代价是透传辅助逻辑改动。
20. OCR 资金基础与供应商生命周期分开验收；代价是额外审查时间。
21. Redis 回执只能证明已观察事实；无法确认的资金效果会停留待核对。
22. OCR 使用关闭隐式重试的专用 Redis 客户端；代价是独立连接池。
23. 正 OCR 单价低于额度精度就拒绝，显式零可免费；存在最低可表示价格。
24. OCR 预扣后只同渠道切换账号；跨渠道备用能力更窄。
25. 引入固定 pdfcpu 及必要依赖升级；代价是依赖与回归范围增加。
26. OCR 对象保留七天并续发短期授权；代价是授权元数据与清理逻辑。
27. 理解、语音、生成图片分段验收；代价是更多审查门禁。
28. Flash ASR 不伪造时间戳；首批该模型没有时间戳输出。
29. OCR 首次交付期限七天；过期后已执行任务仍可能结算但没有可下载结果。
30. OCR 普通日志用回执去重；代价是日志库私有表与投递流程。
31. ClickHouse 暂不接 OCR 事务去重投递；该日志库缺少普通 OCR 消费展示。
32. 额度耗尽的有效创建令牌仍可读所属 OCR 状态；代价是狭窄鉴权分支。
33. 严格媒体限制只接受可验证事实；部分远程媒体会被拒绝。
34. Omni 非音频余量按基础倍率计费；首批没有独立视觉价格。
35. fps 按实际模型契约判断；未证明支持的取值会拒绝。
36. 选定 Omni 首批仅直接非流式 Chat/Responses；透传与自动跨协议转换暂不可用。
37. 明确零用量保持零，按次价格照收；代价是新增权威零值路径。
38. MiniMax 首批按次计费、MP3 二进制流；不提供字符单价或原生 SSE 输出。
39. 仅允许已核对公共音色；私有/克隆音色暂不能池化。
40. 生图请求数、结果数、原生用量必须一致；供应商不一致结果可能被拒绝。
41. 编辑首批仅上传 PNG/JPEG，提示词使用本地字节上限；输入范围较供应商完整能力窄。
42. 显式图像尺寸要求 16 倍数；部分供应商可归整尺寸在预扣前被拒绝。
43. 增加视频快照与独立授权配置；代价是资源服务、清理和部署配置。
44. 视频快照首批仅无音轨 baseline H.264 MP4；格式范围较窄且不证明画面质量。
45. 多模态向量固定 fps=1 和本地数量/大小界限；其他采样语义需要新空间。
46. 管理 API 与界面分开验收；代价是额外门禁时间。
47. 多模态向量使用明确预留与实际用量上限；占用较多额度，超上限结果可能已被上游计费。
48. 同步向量允许预算内重放，畸形成功结果不重试；响应丢失可能造成供应商重复计算费用。
49. 迟到失败归因发送时配额组；错误旧组配置可能需要人工恢复。
50. 允许独立消费者工具与后端并行；代价是显式文件归属和审查协调。
51. 暂停不取消已准入请求；在途请求可能继续完成。
52. 界面与独立消费者联调并行，错开资源构建；代价是构建窗口管理。
53. 专用 OCR 拒绝通用聊天探测；暂没有自动付费原生连通性测试。
54. 管理界面保留目录的一跳模型并补充有效旧式映射链尾；混合配置可能出现额外候选，需以协议回归防止恢复错作用域。
