# LLMRouter v0.1.0-rc.44

本版把公开 /sign-up 与默认 /sign-in 对齐到同一身份域：产品集成或浏览器 SSO
启用时，注册走 UniHub/Casdoor 密码权威；预置本地账号通过仅针对
401 invalid_credentials 的兼容桥降级到 /api/user/login；?native=1 仍显式使用
本地域。包含 7 种语言文案与聚焦测试。前端 web/dist 重新构建，二进制以
//go:embed web/dist 内嵌新前端与 12 个 install/bin 辅助程序。
