# LLMRouter v0.1.0-rc.61

## 中文

- 修复 Qwen 与 MiniMax 的流式工具调用。后续分片中的空占位按字段缺省处理，完整工具调用仍校验 ID、函数名和 JSON 参数。
- 模型列表返回已配置的上游目标、调用端点和能力。Chat Completions 在可写入响应头时标出请求模型和最终选中的路由目标。多模态向量模型需要有效路由才会出现在目录。
- 修复普通 Key 使用统一钱包提交 PaddleOCR 时的 502。发往供应商前确认资金预留有效，并回收超时且从未提交的普通 Key 任务。

## English

- Fix Qwen and MiniMax streamed tool calls by treating null delta placeholders as omitted fields while continuing to validate full call IDs, names, and JSON arguments.
- Expose configured upstream targets, endpoints, and capabilities in model discovery. Chat Completions identifies the requested model and selected gateway target when response headers can still be set. Multimodal embedding entries require a valid route.
- Fix PaddleOCR submission for native keys funded by the unified wallet. Verify the funding reservation before dispatch and release abandoned native jobs that never submitted upstream.
