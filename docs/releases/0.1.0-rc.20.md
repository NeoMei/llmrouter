# 0.1.0-rc.20 — Linux amd64 server preview

- Keep API Key action menus and Key popovers open during asynchronous Key loading and the 30-second relative-time refresh.
- Use each Key's real ID for table row identity so a background refresh cannot transfer selection or open-menu state to a different Key.
- Add controlled browser regressions for asynchronous loading, time updates and replacement rows; the focused suite passes all 10 cases.

This release changes only frontend interaction and its tests. Backend code,
database schema, dependency versions, billing rules, model limits and runtime
credentials remain unchanged. The only deployment environment change is VERSION.
Preserve the existing read-only finance gate and leave the full finance gate unset.

Source review, type checking, lint, formatting and the production frontend build
passed for this candidate. Exact-commit hosted CI, isolated restore, deployment,
public frontend readback and GitHub asset verification are recorded separately.
The two live small-charge acceptance calls were performed on rc19 before this
release; they are not post-rc20 model-call evidence.

This is a Linux amd64 server preview, published as a prerelease and not latest.
It does not enable formal native plans, introduce approved CREDIT pricing, or
claim real merchant payment, desktop installation, signing/notarization or GA
certification. No model or payment request is required for this release validation.
