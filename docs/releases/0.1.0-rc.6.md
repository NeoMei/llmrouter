# LLMRouter v0.1.0-rc.6

候选准备日期：2026-10-27。此服务端预发布版本合并原生多模态计量与 UniHub 公共身份、授权、预留和结算边界。

## 更新内容

- 启用 UniHub 的部署仅接受 UniHub 公共身份和模型授权；原生身份、钱包、订阅、密钥及计费管理入口仅允许显式配置的回环管理监听器访问，并继续要求原生管理员认证。
- 对话保留互斥 token 计费及严格的单次请求价格契约，支持供应商实际 usage 字段别名；请求重放不再次发送供应商。
- 保留主分支的原生对话、embedding、语音、转写、图片、OCR 和视频计量、异步生命周期和待核对恢复；所有平台操作及任务读取统一经过 UniHub 启用策略检查。
- 原生计费查询与管理员核对接口同样执行私有管理边界，不能绕过公共 UniHub 入口。

## 验证范围

[2026-10-27 验收记录](../unihub-owned-acceptance-2026-10-27.md)记录了 22 个公开对话模型的真实供应商响应：全部 HTTP 200、CNY/6 结算、每个逻辑调用一次供应商尝试，并拒绝重复调用。此记录来自合并前的已部署候选；合并后的软件验证以本次测试记录为准，部署回读需要另行完成。

UniHub 充值和会员资金来源为沙盒，未验证真实商户收款或会员激活；不能据此宣称真实支付已通过。22 模型验收不覆盖其他模态的真实供应商认证。

本次发布范围为服务端预发布。未认证桌面安装、签名、公证或容器供应链，不声明 GA，也不替代现有完整发布工作流的认证门禁。发布前备份数据库与配置；无法确认的供应商结果继续保留待核对，不自动退款或重放。
