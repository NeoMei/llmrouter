# LLMRouter v0.1.0-rc.22 — Linux amd64 server preview

Fix OpenAI-compatible Qwen image generation when its route declares image and pixel limits. A valid, explicit image size is checked against the selected route before any reservation. The response's actual dimensions and image count are checked again before output and settlement.

The fix preserves native pricing, the original managed Key, payer, wallet and existing selected models. It does not remove route limits or change supplier credentials. Unknown dimensions and unverified providers remain rejected; a fallback candidate cannot reuse another provider's validation.

This version includes the rc.21 one-Key native catalog and OCR improvements. The forward deployment from the validated rc.21 candidate preserves the database schema and existing OCR objects. The only required environment change is `VERSION=0.1.0-rc.22`; release artifacts and runtime acceptance are recorded separately.

This prerelease targets the Linux amd64 server. It does not certify desktop builds or general availability.
